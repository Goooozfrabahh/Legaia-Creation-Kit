# Legaia Creation Kit v2.1

Release: November 13, 2026
Milestone: Native 128x128 Unified World Region

## Verified milestone

- LCK exports an experimental native MAP region expansion.
- The resulting Legend of Legaia IMG was tested in DuckStation.
- Vahn was shown exploring and viewing terrain beyond Rim Elm's original exterior boundaries.
- Native region expansion was implemented through the game data rather than replacing the retail renderer.
- LCK retains the existing native export, object placement, floor, collision and world-editing toolchain.

## Important limits

This checkpoint does not claim that every native MAP edge, character,
warp, story transition, door, collision surface or imported object has
been validated. The remaining engine integration and generalization
to all scene variants are continued development tasks.

## Release identity

- LCK display version: v2.1
- Studio Cargo package: 2.1.0
- Git branch: lck/v2.1
- Release tag: lck-v2.1.0

## Preservation policy

The original retail IMG, user project files and emulator saves are not
included in this source release. Local executable/source backups are
created before installation.
