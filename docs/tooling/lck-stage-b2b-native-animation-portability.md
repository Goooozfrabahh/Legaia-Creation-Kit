## Native writer

`native_animation` resolves scene-local MAN skeletal actors through their original model selector and the canonical B1 resource inventory. It validates the selected ANM record against the native TMD object count and preserves the Base Form's initial visual-center pivot while compiling the actor's native root. Choosing another compatible Reference clip does not redefine that Base Form pivot. Original MAN, model, encoded carrier, decoded ANM bank and exact clip hashes/addresses are retained. Per-Reference reports include donor provenance and the registered model hash; shared resource reports retain canonical texture dependency and B2A behavior evidence. Descriptor-borne and raw typed-stream donor banks are identified independently from their type labels.

An actor-specific canonical context adds all eight genuine field-character TIM uploads between boot residency and scene uploads. Its words and written coverage must equal the independent complete field-character uploader. B1 static context resolution is unchanged. Destination allocations protect complete resident character and alternate-face uploads, boot residency, destination uploads and native display/capture reservations. Actual image/CLUT contributors and mixed sampling depths still use B1's ordered ownership/relocation planner. Missing observed words remain writer failures.

The compiler registers models through the existing native descriptor/PAC writer, preserving all original selector identities. It merges exact ANM records into the destination singleton type-5 bank, preserving all existing clip IDs/payloads and sharing byte-identical new clips. Type 6 remains the CLUT walker, not a clip bank.

New actor References receive appended MAN partition-1 records and distinct native context IDs. The original SCUS installer/initializer, rather than a replacement editor reader alone, is exercised by the automated probes. Native type-2 model registration and original clip binding are independently checked. P2 context operands are remapped through the existing strict native context relocator when P1 grows; native motion-table binding IDs are updated with that same shift. Unsupported aliases/decode gaps fail the transaction. The B2A inventory's motion binding now correctly uses `N0 + P1 index`, the actor's native `+0x50` identity.

A small new spawn prologue sets only that Reference's compatible transform and explicitly rebinds its clip. The rebind resets the randomized initial phase that the native installer would otherwise choose. No donor dialogue, story/trigger or motion-VM bytecode is copied. Stationary ANM playback and donor ambient movement are separate capabilities.

## Supported class and limits

Supported writer class: detached, scene-bank skeletal field actors whose native model object table matches the selected canonical ANM record. Donor ANM carriers may be descriptors or typed streams. The complete destination model-registration walk must be carried by the verified descriptor/PAC pair. Source MAN/ANM payloads must match the actual last native writers, and the destination must have a single active native MAN descriptor and a single active type-5 ANM descriptor; streamed destination MAN/ANM replacement is not implemented. Descriptor/PAC geometry and texture registration continue through B1.

Compatible state/transform subset: initial frame zero; exact native half-tile/tile-center X/Z root coordinates; integer absolute Y; representable yaw; positive uniform native fixed-point scale. Pitch/roll composition, anisotropic scale and arbitrary initial-frame state fail explicitly. The visual-center/native-root distinction is preserved; a visual center is not silently written as a root coordinate.

MAP/P0-bound animated props (including scripted doors/elevators), global/party/equipment model banks, source records requiring scripts to discover their initial clip, VDF/effects/stagers, ambient movement transplantation, palette/script producers, dialogue, triggers, story conditions and dynamic actor/animation switching are not behavior-preserving portable mechanisms in B2B. Matching a bone count is a native representation check, not animation/behavior certification for an unrelated rig. Explicit clip choices remain choices within the donor bank and must pass native structural validation.

Native encoded arena and known model-table conflict boundaries remain enforced. The allocation profile and original instruction probes do not establish live heap capacity, fragmentation, rendering completion or gameplay. Unknown assets remain in their existing Object Window categories; no town/object allowlist is introduced. The B1.1 raw unregistered-source Object Window adapter and the 45 unresolved static-material identities remain separate outstanding work.
